Title: Ringside: the in-play book that can't be courtsided (Solana + MagicBlock)

Description:
Ringside is an in-play fight exchange on Solana. The fight and the order book run in the same MagicBlock ephemeral rollup, ten ticks a second, and every order is stamped with the tick it was priced on. If the fight has moved on, the program rejects the order onchain.

Measured on devnet across 23 held-out matches: a delayed book accepted 319 stale fills; Ringside accepted 0 and rejected 1,283 stale orders onchain. Median tick 100 ms. 60/60 private reads denied. 19/19 replays verified (10,266 ticks).
